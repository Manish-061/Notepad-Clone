# 📝 Notepad Clone

A simple **Notepad Clone** built using **Java Swing** with features like **Dark Mode**, **Undo/Redo**, **Word Count**, and **Basic Text Editing**.

## 🚀 Features
- 📝 **New, Open, Save, and Print files**
- ✂️ **Cut, Copy, Paste, Select All**
- 🔄 **Undo/Redo**
- 🔍 **Zoom In/Out**
- 🌙 **Dark Mode** (Toggles between light and dark themes)
- 🔢 **Live Word Count**

## ⌨️ Shortcut Keys
- **New**: `Ctrl + N`
- **Open**: `Ctrl + O`
- **Save**: `Ctrl + S`
- **Print**: `Ctrl + P`
- **Exit**: `Ctrl + Esc`
- **Copy**: `Ctrl + C`
- **Cut**: `Ctrl + X`
- **Paste**: `Ctrl + V`
- **Undo**: `Ctrl + Z`
- **Redo**: `Ctrl + Y`
- **Select All**: `Ctrl + A`
- **Zoom In**: `Ctrl + +`
- **Zoom Out**: `Ctrl + -`
- **Help (About)**: `Ctrl + H`
- **Toggle Dark Mode**: Menu Option
